# 📚 Read Journey

## 🔗 [Live Demo](https://read-journey-beryl.vercel.app/) | 🎨 [Figma Design](https://www.figma.com/file/z3m0rdBcEfLTJUBDkAKhWQ/BOOKS-READING?type=design&node-id=18743%3A4973&mode=design&t=Hi1KTaUJMogWXZzz-1)

**Read Journey** is a modern, feature-rich web application designed to help users track, manage, and enjoy their reading progress. The app allows users to explore recommended books, build a personal library, filter and sort readings, and track real-time reading statistics and diaries.

## 🚀 Key Features

* **User Authentication & Authorization** — Secure registration, login, token management, and automatic redirection powered by a custom backend API and **Redux Toolkit**.
* **Responsive Dashboard Layout** — A flexible, reusable wrapper component (`Dashboard`) that adapts seamlessly across mobile (320px+), tablet (768px+), and desktop (1440px+) viewports.
* **Navigation & Burger Menu** — Convenient header navigation with active route highlighting and a responsive mobile burger menu.
* **Recommended Books Catalog** — Explore curated books with server-side pagination, search/filtering options, and detailed modals allowing users to add books straight to their library.
* **Personal Library Management** — Organize books by reading status (*Unread*, *In progress*, *Done*), view detailed info via interactive modals, and remove books when needed.
* **Interactive Reading Tracker** — Record reading sessions by entering start and finish pages, monitor real-time reading speed, view detailed reading diaries organized by date, and track visual progress via charts.
* **Notifications & Validation** — Fully validated forms (using **Formik** / **React Hook Form** & **Yup**) and sleek feedback notifications via **react-hot-toast**.

## 🛠 Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **State Management:** Redux Toolkit
* **Data Fetching & Caching:** TanStack React Query
* **API Client:** Axios
* **Form Validation:** Formik & Yup (or React Hook Form)
* **Styling:** CSS Modules
* **Notifications:** React Hot Toast
* **Icons:** React Icons
* **Deployment:** Vercel
